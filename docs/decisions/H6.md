# H6: guides catch up with B12 and the H1 to H5 fixes

## Summary

A documentation unit from the completeness and security review. The developer guide's section
14 ("Not ready yet") still listed things later units built, and the guide sections, `DOMAIN.md`
and the other guides did not yet describe what the fix units H1 to H5 changed. H6 corrects the
stale rows and writes the guide text for each fix once it has merged into `feat/platform-gaps`:

- F6/B12: the "packages installed but not used yet" row names only `@mastra/memory`; B12's
  persisted query cache uses the React Query persister.
- H1 (notifications): approval requests reach their deciders by push, the in-app inbox,
  WhatsApp, then email; an undo window holds notifications and outbox sends; notification
  parameters are projected for each recipient; notifications are scheduled from stored events.
- H2 (settings writers): the routes that change the `money`, `approvals`, `businessHours`, `sla`
  and `memory` settings sections.
- H3 (credits and MCP): embedding and guardrail tokens are metered; agent tool calls are refused at
  100% of a cap; MCP tools carry annotations; a switched-off flag hides its MCP tools.
- H4 (privacy): the calendar, call-log, integration-payload, OAuth and acceptance parts of export
  and erasure.
- H5 (orders): the orders connector and the accepted state.

No code changes. The guide text describes what the merged code does, read from the code and the
units' own decisions docs, not from their briefs.
